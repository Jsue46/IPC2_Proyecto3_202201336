# Full-Stack Web Platform with XML Processing — Django & SQLite

Academic project developed for the **Introduction to Programming and Computing 2** course at the Universidad de San Carlos de Guatemala (First Semester 2024).

This repository contains a full-stack web application built with Django, SQLite, and frontend templates, integrating XML dataset ingestion, relational database storage, and interactive data visualization.

---

## Overview

The platform allows users to upload structured XML configuration and transaction datasets, processes the incoming payloads through backend verification routines, persists models into SQLite, and provides administrative dashboards to query statistics, generate financial/operational summaries, and download reports.

---

## Key Features

- End-to-end web architecture powered by Django
- Custom XML parser and schema validator
- Relational data modeling with Django ORM and SQLite
- Interactive dashboard for data inspection, transactions, and user management
- Automated report generation and export capabilities

---

## Technologies

- **Backend:** Python 3, Django
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript
- **Data Exchange:** XML
